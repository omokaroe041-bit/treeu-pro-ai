TREEU PRO AI - GitHub Pages PWA prototype

UPLOAD
1. Extract this ZIP file.
2. Upload all five files directly into the root of your GitHub repository.
3. Commit the changes.
4. In GitHub open Settings > Pages.
5. Under Build and deployment choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish the site. Open the published HTTPS URL in Chrome on Android.
8. In Chrome use the menu (three dots) > Install app or Add to Home screen.

IMPORTANT
This is only a front-end demo/prototype. It does not receive live market prices,
generate verified AI predictions, connect to MT5, or execute trades.
The random demo display is illustrative only.
An Android PWA cannot run MT5 Expert Advisors. MT5 automation requires a
supported desktop/Windows MT5 environment or suitable remote host and secure setup.
